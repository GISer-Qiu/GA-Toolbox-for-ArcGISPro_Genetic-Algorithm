# GA-Toolbox-for-ArcGISPro_Genetic-Algorithm
> 2026年 易智瑞GIS开发竞赛 - 地理设计组 参赛作品 (部分)

一个使用Python语言编写的、运行在ArcGIS Pro的遗传算法工具箱，可用于最优路径规划。A genetic algorithm toolbox written in Python and running on ArcGIS Pro, which can be used for optimal path planning.

适合的软件及版本：GeoScene Pro 6.1 或 ArcGIS Pro (暂未测试，适用版本未知)
